## Configuration (`config.txt`)
The `config.txt` file lets you customize runtime settings without recompiling the executable:
* **`version_date`**: Sets the version date shown at startup.
* **`developers`**: Semicolon-separated list of group members.
* **`default_text`**: Initial text shown by the marquee.
* **`default_speed_ms`**: Initial animation delay in milliseconds.
* **`console_width`**: Character width of the marquee bounce boundary.

## How to Run
To compile this project, type:
```bash
g++ marquee.cpp -o marquee.exe
```
